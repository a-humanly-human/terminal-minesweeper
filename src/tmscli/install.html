installation & usage

Get tmscli running in your terminal in seconds.

Install from PyPI

pip install tmscli

Once installed, the tmscli command becomes available in your terminal.

Basic usage

1. Start the game

tmscli

Launches Minesweeper directly in your terminal with the default board.

2. Set the board size

tmscli --size 10

Or use the short form:

tmscli -s 10

Adjust the board size to set your own difficulty.

3. Controls

Use the arrow keys to move, space to reveal, and f to flag a cell. (Exact keys may vary — check the in‑game help.)

Version note

v0.3.0 added a border to the minesweeper format and minor bug fixes. Update with:

pip install --upgrade tmscli
