installation & usage

A guide on how to install tmscli from pypi to how to customise number of mines and the size of the board.

Dependencies

Install Python

https://www.python.org/getit/windows/

Check for Pip

first check

pip --version

If a version shows up, precede to Install from PyPi


If "Not Recognized" appears, follow the pip installation

Installing pip

python -m ensurepip --upgrade

then repeat the previous command (pip --version) to check for success

Install from PyPI

pip install tmscli

Basic usage

tms

Launches the basic 9x9 board with 10 mines

Size

tms -s SIZE

customises the boards size

Number of mines

tms -m NUM

customises number of mines

Rules

tms -r

prints the rules

In-game commands

uc x y

uncovers square (x,y)

fl x y

flags square (x,y)

uf x y

unflags square (x,y)
